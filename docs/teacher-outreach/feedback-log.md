# Teacher feedback log

A running record of what real teachers told us, what we changed, and
what we learned. Update this file the same week a reply arrives.

## Rules

- Log first name and grade only, plus the device and the number or
  range they used. Never put a teacher's full name, email address,
  school name, or any student name, photo, or work in this repo.
- Quote the point that matters in the teacher's own words, briefly.
  Do not paraphrase a complaint into something softer than it was.
- Every point gets a triage: bug, confusion to fix, missing feature
  to consider, or question answered by email.
- Link the GitHub issue or PR when a point turns into work. Link
  nothing when it was answered by email, and say so.
- When a fix ships, reply to the teacher and note the date here.
  An entry is not done until the teacher has heard back.
