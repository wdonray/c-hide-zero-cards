## Folder version (live Nov 17, 2026)

Chaley suggested TpT resources should be a folder: instructions
first, then printable versions. The folder replaced the single
one-page PDF above when Donray approved it Nov 17, 2026, and
was uploaded as the main file the same day, 10:13 AM EST,
28.08 kB on TpT. All three PDFs are US Letter, built by
`generate-tpt-pdfs.py` in this folder (ReportLab, same style as
the original lesson PDF), and zipped as
`hide-zero-cards-tpt-folder.zip` for upload.

- `01-Teacher-Instructions-Hide-Zero-Cards.pdf` (1 page):
  the lesson reworked website-first. Leads with
  hidezerocards.org as the easier path (no printing or cutting
  needed), then the 10-minute lesson steps, the "Try these
  numbers" examples, talk prompts, and the feedback email.
- `02-Print-and-Cut-Cards-Black-and-White.pdf` (6 pages):
  Hide Zero Cards to 1,000, ones, tens, hundreds, thousands,
  digits 0-9, 40 cards. Grayscale throughout. The cards use the
  app's own math from `lib/cardLayout.ts`: each card is the
  natural text width of the full value, commas included, and the
  digits are letter-spaced at 0.3x the font size, so the covering
  card's edge always lands in whitespace. Stack them by lining
  up the right edges, widest card first, and the peek of each
  card is exactly its leading digit, plus the comma for a
  group-final card, so the fan reads like the formatted number
  ("3,743"). Scaled to the largest size that fits US Letter (a
  ones card of about 1.4 in; a playing-card-sized ones card
  would make the thousands card 14 in wide). Six pages: ones 1,
  tens 1, hundreds 2, thousands 2. Card values follow the app's
  `formatCardValue()`, including the comma ("1,000") and the
  leading-zero form of zero cards ("00", "000", "0,000").
- `03-Print-and-Cut-Cards-Color.pdf` (6 pages): the same 40
  arrow cards in the app's production card colors from
  `lib/constants.ts` CARD_PAINT (ones #DC2626, tens #B91C1C,
  hundreds #991B1B, thousands #A16207, each with its darker
  gradient stop). Card values follow the app's
  `formatCardValue()`, including the leading-zero form of zero
  cards ("00", "000", "0,000").

Place Value Made Fun with Hide Zero Cards

A free, engaging online tool

Try it live: https://hidezerocards.org

A free 10-minute place value lesson for elementary classrooms,
built around Hide Zero Cards. This folder has the lesson plus
print-and-cut cards to 1,000, so you can use the free tool on
screen or the cards in small groups and centers.

Roll or type a number, and it fans out as color coded place
value cards. Tap Hide zeros and the zero cards hide in place,
so 3,743 reads as 3, 7, 4, 3 while the class talks about what
each digit is worth. Pull the 3 card out and it shows 3,000.

What is inside:

- 01 Teacher Instructions: the 10-minute lesson plan, website
  first, no printing required
- 02 Print and Cut Cards, Black and White: cards to 1,000 for
  any printer, 4 pages
- 03 Print and Cut Cards, Color: the same cards in the app
  colors, 4 pages
- Steps for Roll, Hide zeros, Mix and rebuild, and Number Forms
- Three numbers to try: 3,743, 2,609, and 180,736
- Talk prompts for the class
- How to set the Roll range from up to 100 to up to
  1,000,000,000 for the level you are teaching

The tool is free, with no login, no ads, and no student
accounts. It works on projectors, smartboards, tablets, and
Chromebooks, in light or dark mode, with a built-in teacher's
guide in the app.
